# Editorial QA — the human counterpart to the integrity gate

Run before any push that publishes a new seal or changes the Story Engine.
The integrity gate checks the numbers; this checklist checks the writing.
(Adopted 2026-07-27, per the Editorial Operations phase.)

## Before publication
- [ ] Read the Ooze Report OUT LOUD — awkward transitions don't survive a voice
- [ ] Household story matches the data (spot-check every number against latest.json)
- [ ] No duplicated sentences across sections of the same document
- [ ] Confidence statement accurate (methodology version, stale count, revision count)
- [ ] All indicator sentences grammatical — watch plural lines (gas prices/credit cards/auto loans) and 1-point singulars
- [ ] Links valid (article, Specimen Progress, indicator pages)
- [ ] Newsletter reads naturally as an email — would you finish it?
- [ ] Social copy under platform limits (~280 chars) and self-contained
- [ ] No unsupported claims — nothing the data doesn't literally show
- [ ] Historical comparisons verified against history.json
- [ ] Formats feel native: homepage ≠ RSS ≠ report ≠ social (same facts, different presentation)
- [ ] Is it still fun? (Department of Fun retains veto)

## Voice rules (the Story Engine's editorial identity — protect story.js)
- Plain words; a sentence a neighbor would say out loud
- Numbers carry the drama; adjectives don't ("down 11 points," never "plummeting")
- Never predict; never sensationalize hardship; the meter measures
- The jar is the subject when the whole economy moves; the line is the subject when one thing moves
- Aux sensors always marked observed-not-scored; stale feeds always disclosed
- One idea per sentence in line-by-line sections
