# Teaching Notes

- The course exists to make every OOZEMeter intake line explainable, reproducible, and defensible.
- Prefer direct, dense instruction with a visible data trail.
- Each lesson should answer: what is measured, why it matters, where the data lives, how often it changes, how it can mislead, and how OOZEMeter should use it.
- Use the containment-lab visual language, but never let the theme obscure units, dates, source ownership, proxies, or uncertainty.
- Do not create learning records until the learner demonstrates understanding through an exercise or follow-up discussion.
